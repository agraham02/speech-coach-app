# Codebase cleanup, 2026-10-23

Done on `feature/tono-ai` before creating `staging`. Type-check clean, 1,213 tests passing before and after (no test covered the deleted code).

## Removed

- **`teleprompter-prototype/`**: a standalone Vite web prototype (26 tracked files), excluded from the app's tsconfig and referenced nowhere. In git history if needed.
- **`test.md`**: the old "iPhone test checklist (temporary)", 72 unticked boxes from an early build. Replaced by `docs/testing/device-test-plan.md`.
- **`@expo/ngrok`** dev dependency (tunnel support nothing uses), and its 32 transitive packages.
- **19 exports defined and never referenced anywhere** (not even in tests): `DateField` (and its styles), `lessonsForSkill`, `getLine` and `LINE_SOURCES`, `setGap`, `EYE_CONTACT_MAX_DEG`, `ON_DEVICE_STEPS`, `isScoredPractice`, `categoryLabel`, `isSignedIn`, `modelPath`, `deleteSelfLike` and `restoreSelfLike`, `updateSessionStatus`, `isRunning`, `discardPresenceTimeline`, `setGeminiApiKey`, `getVideoFileSize`, `cloudReviewAvailable`, and the whole Gemini "clean the transcript only" path (`cleanTranscriptOnly`, its schema and prompt builder).
- **Unused imports and locals**: 17 imports in 14 files, `getGreeting` in `HomeScreen`, an unused style parameter in `StepDots`.

## Moved

The four finished build plans moved from the repo root to `docs/history/` (`plan.md`, `practice-expansion-plan.md`, `conversation-plan.md`, `design-refresh-plan.md`), and the README and source comments that pointed at them were updated.

## Added to `.gitignore`

`analysis_samples/` (real recordings' transcripts; the repo is public) and `supabase/.temp/` (local CLI state).

## Deliberately not touched

These need a decision or belong to a coming session.

- **`buffer` and `react-native-gesture-handler` dependencies.** Knip reports them as unused, but libraries may rely on them being hoisted (for a global `Buffer`, or as a peer dependency), and gesture-handler is native code. Verify by removing one at a time and building.
- **The old curriculum engine in `src/domain/curriculum.ts`.** `evaluateCurriculum` and its composite-score helpers have no callers since the path engine replaced them. Session 07 audits scoring and the curriculum, so it should decide whether this goes. `recomputeCurriculumLevel` still takes a `recentDrills` value it never reads.
- **About 55 exports used only inside their own file.** The `export` keyword is unnecessary but harmless; not worth the churn. 45 exported types are the same.
- **BYOK code** (`providers.ts`, `AiCoachSetup.tsx`, `DeepReviewSettings.tsx`, `lessons.ts`, the secrets store). Session 08 removes it.
- **`README.md`** is out of date (it still calls this an unpublished personal app with phases). **`app-store-launch-checklist.md`** still says "no account and no server" and describes own-key reviews. Both need a rewrite once the architecture is settled (session 08).
- **`spikes/inference-eval/`** at the repo root belongs with `docs/research/spikes/`; moving it would break the paths in the decision doc, so it stays until that doc is next edited.
- **`.claude/settings.json`** has uncommitted local browser-domain permissions; left out of the commits on purpose.

## How to re-run the checks

```
npx knip --no-progress --reporter compact
npx tsc --noEmit --noUnusedLocals --noUnusedParameters
```

Knip reports `supabase/functions` (Deno entry points) and `plugins/withMediaPipeLinkerFlags.js` (loaded by name from `app.config.ts`) as unused files; both are used.
